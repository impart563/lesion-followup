# Changelog

## 0.2.0 — 2026-10-26

- Add combined visit/text observation filters with visible counts and clear action;
  filtering preserves source inputs, review bindings and full report contents.
- Link current quality and human-review hints to the matching visit and target
  form, including omitted observations; stale review notes cannot navigate.
- Add independent exact-version registry installation verification across four backends.

- Add complete per-target observation entry with baseline context, state-specific
  fields, core validation, before/after preview and one-step input-history restore.
- Extend the independent consumer to text parsing/preflight, valid NE handling,
  bilingual bundles and tamper rejection on all four supported backends.
- Refresh candidate preparation to rc.3 with version-2 source-count manifests
  and a standalone verifier for source/module/browser consistency and checksums.

- Add whole-visit creation with one blank missing observation per baseline
  target, and previewed metadata updates/removal validated by the MoonBit core.
- Add current-input undo/redo with focused-field grouping, bounded in-memory
  retention, exact raw-text restoration and resets when loading another case.

- Add complete review handoff ZIPs containing portable source sessions,
  native-compatible current reports and optional input-bound human notes.
- Add strict outer/nested integrity checks and regeneration of every report
  file before displaying a derived handoff preview.
- Add explicit whole-workspace restoration with stale-operation guards,
  no-note clearing and preserved local draft/note copies.

- Add a manual review checklist preserving core hints while tracking human
  viewing states, per-item comments and a round-level summary.
- Add explicit local and portable note persistence with strict schemas,
  independent SHA-256 verification and current-input/core-hint binding.
- Add bilingual standalone HTML/Markdown review explanations, with pending
  work preserved and stale snapshots kept read-only for JSON backup.

- Add independent browser batch review of portable sessions, per-case failures,
  explicit record opening and native-rendered report indexes.
- Add deterministic ZIP delivery for current and batch reports, with five-file
  contents matching native bundles and successful native verification after export.
- Add bounded stored/DEFLATE ZIP import, path/CRC checks and per-directory core
  bundle validation without executing imported HTML or replacing editor inputs.

- Add workbench selection of the complete synthetic example collection, including
  a paired revision example with its original comparison version.
- Add a strict browser comparison action with independent input preflights and
  native-equivalent JSON, Markdown and HTML revision reports.
- Add a workbench comparison view with fixed reference inputs, measurement and
  downstream evidence, source fingerprints and immediate stale-result withdrawal.
- Add portable review sessions that retain both source pairs and unfinished text,
  verify a canonical SHA-256 payload, and recompute evidence after restoration.

## 0.2.0 — release candidate, 2026-10-25

- Added a reproducible four-case collection with hand-calculated expectations,
  importable workbench drafts, revision evidence and matching batch results.
- Added Windows 2022 and Ubuntu 24.04 clean-checkout CI, including Unicode paths,
  browser HTTP entry checks and preserved per-platform acceptance records.
- Added a bundled loopback server with explicit ES-module MIME types, handling
  Windows system mappings and hostname differences during local startup.
- Added extracted-package consumer checks on all four supported backends and a
  clean-commit release-candidate builder with source, browser and module archives,
  SHA-256 checksums and a publication-state manifest.
- Documented version compatibility, input contracts and separate candidate,
  GitHub Release and Mooncakes publication steps. Candidate preparation does not
  imply registry availability.

- Add an offline browser workbench for paired input import, baseline/observation
  editing, located diagnostics, five-format export and current-report review.
- Add explicit local and portable draft saving/restoring with strict version
  checks; input changes immediately invalidate earlier reports and print views.
- Add summary/full-evidence A4 print layouts with matching input fingerprints,
  repeated table headings and long-track pagination checks.
- Add a shape-only CSV cell decoder and an `editor` browser action, retaining
  invalid clinical values for correction while the existing preflight gates replay.
- Refine workbench navigation, tables, state messages and Chinese copy.

- Expand exact per-visit calculation conditions with gate and priority context,
  available through typed checks and bilingual HTML/Markdown/JSON reports.
- Compare independently replayed revisions by visit/target identity, preserving
  input changes and downstream minimum/category effects.
- Add version-2 deterministic bundle provenance, SHA-256 and byte-length checks,
  plus read-only validation of fixed artifacts and semantic input metadata.
- Add isolated batch review with manifest-relative paths, portable case IDs,
  per-case failure records, linked indexes and a partial-failure exit status.

- Generate matched single- and multi-target synthetic input templates in a new,
  overwrite-protected directory, with English or Chinese filling instructions.
- Add source-located input-quality preflight, separating blocking errors from
  missing measurements, defaults, technique changes and context-review hints.
- Add Chinese HTML, Markdown, SVG and CLI presentation while preserving machine
  JSON/CSV, identifiers, reader notes and the existing English renderer APIs.
- Add individual-target plots and ledgers, retaining NE observations with hollow
  markers and distinguishing missing values, absence and 5.0 mm defaults.

## 0.1.0 — 2026-10-24

- Add versioned study JSON, long-form CSV and physical input diagnostics.
- Add Markdown, JSON, CSV, SVG and self-contained HTML reports, direct output,

- Verify the root facade, separate module consumer, boundary cases, escaping,
